# Security Policy

## Supported version

The current `main` branch and the deployed GitHub Pages site are supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when available. Do not publish suspected vulnerabilities, credentials, personal data, or proof-of-concept exploits in a public issue.

Include the affected URL or file, reproduction steps, likely impact, and any suggested mitigation. Reports will be reviewed and acknowledged as soon as practical.

## Scope

This is a static portfolio. It does not process credentials, accept form submissions, or expose an application API. Links to external projects have their own security boundaries.
